# Inkbreak
<!-- impeccable:product-schema 1 -->
## Platform
web
## Stack
Approved Three.js browser game. Vite and TypeScript recommended and approved with build instruction. Rapier collision; DOM menus and HUD.
## Users
HNG individual project evaluators and desktop players using keyboard and mouse.
## Product Purpose
A playable original ink arena shooter combining territory control with a five-fighter objective mode.
## Capabilities and Constraints
Four arenas and two milestones: Turf Clash with five selectable classes and abilities; Squad Assault with five fighters per side, live 1–5 switching, AI teammates, bunkers and a protected core. Keyboard and mouse, single-player first. Controller and multiplayer deferred. Target 120 fps and high-quality visuals, measured on actual hardware. No claim of console-level fidelity or universal frame rate.
## Operating Context
The official start.ng contract is implemented for hosted identity and character styling. Source HTML lives under app/ so start.ng can serve the built dist/ entry. The owner alone may push to GitHub; publishing check and approval require that public repo URL. Standalone localhost mode is explicit.
## Brand Commitments
Original Inkbreak working identity; cyan/coral ink and street-sport industrial environments. No Nintendo assets supplied.
## Evidence on Hand
Local source, unit tests, browser smoke harness, production build and static release checker. Browser and hardware performance evidence must be recorded separately. No public GitHub repository URL has been supplied.
