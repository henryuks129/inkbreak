# Inkbreak Implementation Plan

> **For agentic workers:** Execute as coordinated subagent work with root integration and review.

**Goal:** A keyboard-and-mouse Three.js ink arena shooter across four original arenas, with a 120 fps target.

**Architecture:** Fixed-step simulation independent of Three.js; Rapier character and arena collisions; pooled projectiles; authoritative ink grid with a matching texture. DOM menus/HUD and an explicit platform adapter.

**Tech Stack:** Vite, TypeScript, Three.js, Rapier, node test runner through tsx, Playwright.

## Files and task ownership
- Root: package/config, src/main.ts, src/engine.ts, src/world.ts, src/input.ts, src/physics.ts, src/platform.ts, src/style.css, docs.
- Arena agent: src/arenas.ts four arena data definitions.
- Simulation agent: src/simulation.ts and src/simulation.test.ts authoritative ownership/refill/timer tests.

## Sequence
- [ ] Bootstrap dependencies and TypeScript build. Run `npm install`, then `npm run build` once entry files exist.
- [ ] Implement and test authoritative paint ownership, overwrite scoring, refill/clamping and round end/reset with `npm test`.
- [ ] Implement procedural environments and characters, directional lighting/shadows, floor ink texture and Rapier colliders.
- [ ] Implement fixed 120 Hz simulation, camera-relative input, pointer-lock mouse aim, jumping, swim/refill, paint projectiles, AI opponents, damage and respawn.
- [ ] Implement arena selection, practice/turf modes, pause, settings, results and restart. Clear input on blur/pause; clamp catch-up time.
- [ ] Add host identity/appearance adapter boundary with explicit standalone state; no invented start.ng API.
- [ ] Verify `npm test` and `npm run build`; boot `npm run dev`; playtest all four arenas with screenshots, keyboard controls, paint/refill, pause and restart. Record actual frame times and viewport/hardware; do not equate a target with a measurement.
- [ ] Technical and visual review, one batched defect correction, readback and final checkpoint. Start.ng publication remains conditional on its real platform contract/access.

## Tool decisions
No paid media generation required for self-contained procedural 3D assets. Game Studio is runtime authority, the approved street-sport world is design authority, Design Director coordinates roles, and Impeccable supplies review. 21st marketing components, neural trading, and template authoring are not game-runtime dependencies.
